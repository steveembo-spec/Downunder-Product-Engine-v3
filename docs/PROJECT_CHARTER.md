\# Downunder Product Engine v3 - Project Charter



\## Vision



Downunder Product Engine is the Product Control Centre for Downunder Dirtbikes.



It is not just a CSV builder. It is a desktop product management system that connects supplier data, images, descriptions, pricing, reporting, and Shopify.



\## Core Purpose



DPE exists to:



\- Import supplier files

\- Build a central product catalogue

\- Search and manage products quickly

\- Compare suppliers

\- Manage images and descriptions

\- Prepare Shopify-ready data

\- Eventually push and sync products directly with Shopify via API



\## Core Principles



1\. The Build Centre must remain stable.

2\. Existing working features must not be broken.

3\. New features should be added incrementally.

4\. DPE should feel like professional software, not a spreadsheet.

5\. Supplier expansion should not require major code rewrites.

6\. Shopify CSV export remains as a fallback.

7\. Shopify API integration is the long-term direction.

8\. GitHub main branch must always stay stable.



\## Current Baseline



DPE v3.1.0 includes:



\- Working desktop app

\- Build Centre

\- Supplier catalogue build pipeline

\- Shopify-ready CSV output

\- SQLite catalogue foundation

\- GitHub version control



\## Next Major Version



DPE v3.2.0 will focus on:



\- Modular application structure

\- SQLite-powered Catalogue Control Centre

\- Faster product search

\- Product Inspector

\- Supplier comparison foundation



\## Long-Term Direction



DPE should become the master catalogue system for Downunder Dirtbikes, with Shopify acting as the storefront.
